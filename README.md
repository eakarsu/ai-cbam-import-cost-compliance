# CBAM Import Compliance & Cost Optimizer

A domain-specific React, Express, PostgreSQL, and OpenRouter application for the EU CBAM definitive regime.

- 12 specialized capabilities spanning scope, thresholds, supplier evidence, emissions, verification, deductions, certificates, declarants, declarations, and supplier risk.
- 48 editable domain fields and three scenario-fill buttons per capability.
- 15 PostgreSQL seed records per capability (180 total).
- Deterministic emissions and certificate-exposure calculations, professional AI decision briefs, outcome analytics, governed status changes, and an audit trail.

Run `./start.sh`, then open <http://127.0.0.1:4533>. The API runs on `5533`.
